# История изменений

## 1.0.0 — 12 октября 2026

- Подготовлена портфолио-версия командного проекта RasaProject.
- Добавлены README, схема архитектуры, инструкции Telegram/REST, сведения об авторах и MIT License.
- Кэши Rasa, настройки IDE, Python bytecode, архивы моделей и токены удалены из перенесённой истории.
- Код разделён на действия, парсинг, навыки, требования вакансий, зарплатную модель и хранение.
- Исправлены обработка месяцев и нулевого опыта, зарплаты с пробелами и диапазонов, валидация полей до завершения формы, отображение процентов и отсутствие зарплаты.
- Удалён жёсткий путь Windows; подходящие анкеты сохраняются в локальную папку, Excel включается настройкой.
- Убраны обязательная загрузка FastText и обучение/сохранение зарплатной модели при импорте.
- Добавлен лёгкий словарный режим; семантическое сопоставление FastText доступно отдельно.
- Очищены некорректные NLU-примеры, повторяющиеся правила и тестовые действия, которых не было в реализации.
- Зафиксированы зависимости и Python 3.10, добавлены unit-тесты и GitHub Actions.
