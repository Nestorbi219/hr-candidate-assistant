# Авторы и происхождение

Первоначальный командный проект: [hetiyje/RasaProject](https://github.com/hetiyje/RasaProject), февраль 2025 года.

| Участник | Вклад / основание указания |
| --- | --- |
| [hetiyje](https://github.com/hetiyje) | Автор исходных коммитов; разработка командного проекта. |
| [egorvegel](https://github.com/egorvegel) | Автор исходных коммитов, включая коммиты под именем Egor; разработка командного проекта. |
| [Nestorbi219](https://github.com/Nestorbi219) | По описанию участника: скрипт распознавания навыков кандидата, запуск Telegram-бота и test stories. Владелец этой портфолио-версии. |

Вклад Nestorbi219 указан по его собственному описанию: история исходного репозитория не позволяет полностью восстановить распределение задач внутри команды. Авторы существующих коммитов сохранены, чужие коммиты не переатрибутированы.

Портфолио-версия содержит дополнительную очистку структуры, документацию, конфигурацию окружения, исправления обработки анкеты и автоматические проверки. Эти изменения выполнены с помощью Codex.
